# GustavoHerpich.github.io

Live: https://gustavoherpich.github.io

CI: [![CI](https://github.com/GustavoHerpich/GustavoHerpich.github.io/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/GustavoHerpich/GustavoHerpich.github.io/actions/workflows/ci.yml)

One-line description: Personal portfolio website built with Astro, TypeScript, and spec-driven development.

Stack: Astro, TypeScript, Vitest, Playwright, Lighthouse CI

How to run:
- `pnpm install` - Install dependencies
- `pnpm dev` - Run development server
- `pnpm verify` - Run lint, typecheck, tests, and build
- `pnpm e2e` - Run end-to-end accessibility tests
- `pnpm lhci` - Run Lighthouse CI analysis

Built with spec-driven development:
- [openspec/](./openspec/) - Spec-driven change management
- [AI-USAGE.md](/AI-USAGE.md) - AI usage policy
